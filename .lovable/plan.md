
# 2인용 정사각형 대전 게임 🎮

정사각형 캐릭터 2개가 같은 화면에서 대결하는 실시간 2인용 대전 게임입니다.

---

## 🎯 핵심 게임 플레이

### 게임 화면
- 깔끔한 경기장 (테두리가 있는 직사각형 필드)
- 2개의 정사각형 캐릭터 (각 캐릭터별 고유 색상)
- 각 플레이어의 체력바 + 스킬 쿨다운 + 궁극기 게이지 표시
- 현재 라운드 및 점수 표시

### 캐릭터 조작
- **플레이어 1**: WASD로 이동, Space로 일반공격, Q로 스킬, E로 궁극기
- **플레이어 2**: 화살표키로 이동, Enter로 일반공격, Shift로 스킬, /로 궁극기

---

## 🎭 캐릭터 시스템

### 1. 워리어 (Warrior) - 빨간색
- **일반 공격**: 근접 펀치 (중간 데미지, 짧은 사거리)
- **스킬 (쿨다운 3초)**: 돌진 - 전방으로 빠르게 돌진하며 적에게 충돌 시 데미지
- **궁극기 (게이지 100%)**: 분노 폭발 - 주변 광역 데미지 + 일시적 공격력 증가

### 2. 레인저 (Ranger) - 초록색
- **일반 공격**: 화살 발사 (낮은 데미지, 긴 사거리)
- **스킬 (쿨다운 4초)**: 트랩 설치 - 밟으면 슬로우 + 데미지
- **궁극기 (게이지 100%)**: 화살 비 - 맵 전체에 화살비가 내려 광역 데미지

### 3. 탱커 (Tank) - 파란색
- **일반 공격**: 방패 치기 (낮은 데미지, 짧은 사거리, 넉백 효과)
- **스킬 (쿨다운 5초)**: 방어 자세 - 2초간 받는 데미지 70% 감소
- **궁극기 (게이지 100%)**: 지진 - 맵 전체 흔들림 + 적 스턴 2초

### 4. 닌자 (Ninja) - 보라색
- **일반 공격**: 표창 던지기 (낮은 데미지, 중간 사거리, 빠른 공격속도)
- **스킬 (쿨다운 3초)**: 순간이동 - 짧은 거리 텔레포트
- **궁극기 (게이지 100%)**: 그림자 분신 - 3초간 분신 생성, 분신도 공격 가능

---

## ⚡ 전투 시스템

### 기본 메커니즘
- 상대방에게 접근하여 공격하면 데미지
- 체력이 0이 되면 라운드 패배
- 설정한 라운드 수를 먼저 이기는 플레이어 승리

### 궁극기 게이지
- 공격 적중 시 게이지 충전
- 피격 시에도 소량 충전
- 100% 충전 시 궁극기 사용 가능

### 스킬 쿨다운
- 각 캐릭터별 스킬 쿨다운 시간 상이
- UI에 남은 쿨다운 시간 표시

---

## 📊 점수 및 라운드 시스템
- 각 라운드 승자 기록
- 최종 승자 발표 화면
- 라운드 간 짧은 휴식 시간

---

## 🔊 사운드 효과
- 공격 시 효과음 (캐릭터별 다른 소리)
- 피격 시 효과음  
- 스킬/궁극기 사용 효과음
- 라운드 승리/패배 효과음
- 배경음악 (옵션)

---

## ⚙️ 게임 설정
- 라운드 수 선택 (1, 3, 5라운드)
- 라운드 제한 시간 설정
- 사운드 켜기/끄기
- 게임 다시 시작

---

## 🖥️ 화면 구성
1. **메인 메뉴**: 게임 시작, 설정, 조작법 안내
2. **캐릭터 선택**: 각 플레이어가 캐릭터 선택 (1P 먼저, 2P 다음)
3. **게임 화면**: 실제 대전 플레이
4. **결과 화면**: 최종 승자 발표 및 재대결 옵션
