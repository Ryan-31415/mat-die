## 상태와 범위

기준선은 깨끗한 `main`의 `13a8ad4773e1e1c00efce97fa2468675031333e0`이다. 작업 1 궁수 판단과 작업 2 CPU 최적화 및 도구가 반영되어 있음을 확인했다. 로컬 `origin/main`과 일치했지만 GitHub 연결 실패로 실시간 원격 상태는 확인하지 못했다. 기존 커밋·변경을 되돌리지 않았다. 이 작업에서 커밋·푸시·PR을 만들지 않았다.

정글에서는 같은 콜백의 탄환 처리 순서대로 먼저 차단된 탄환의 덩굴 제거와 뒤따르는 탄환의 적중을 구분한다. 무료 기본 공격의 제거에는 작은 가치를 주며 적 피해와 같은 보상을 주지 않는다. 유도탄은 기존 실제 회전율과 궤적 예측을 사용하고, 적 명중 예측일 때만 공격용 스킬로 채택한다. 네이팜의 발화·지대 생성·동시 입력 순서는 기존 엔진과 궁극기 정책을 유지했다. **새로운 네이팜 통로 차단 가치 모델은 구현하지 않았다.**

화산의 실제 실행 규칙은 바닥 접촉 시 500ms 간격의 피해 15(기존 발화 상태면 1.2배), 수직 반동 -900, 3초 발화다. AI는 비공개 마지막 피해 시각이나 미래 환경 이벤트를 읽지 않는다. 기존 바닥 위험·긴급 탈출을 유지하며, 발사 기회 보상으로 바닥 체류를 장려하지 않고 착지 경로 위험을 추가했다. 이번 보완은 수직 착지 경로 검사이며 **장기 복귀 경로 탐색을 새로 구현한 것은 아니다.**

## 추가 수정 1회와 정확성 검사

초기 검사에서 준비된 산탄이 코일에 차단된다는 이유로 기존 무료 생존 공격을 하지 않아, 양 진영의 `ready basic is retained` 장면이 실패했다. 기존 단일 코일 생존 문맥에서는 새 정책 전체를 비활성화해 원래 기본 공격·그물 정책을 사용하도록 수정했다. 이후 코일 장면 18개가 모두 통과했다. 해당 테스트의 기대값은 바꾸지 않았다.

동시에 초기 CPU 검사에서 불필요한 반대 방향 상세 로켓 예측을 확인했다. 이동 후보는 유지하고 실제 공격 정책에서 발사로 채택할 수 없는 방향의 상세 공격 계산을 줄였다. 같은 판단의 상대 예측과 발사 결과를 재사용하고, 새 정책의 캐시/클로저 생성은 두 대상에만 한정했다. 이 수정 후 추가 전술 조정은 하지 않았다.

- 초기 관련 검사: 7파일 114개 통과.
- 최종 수정 후: 6파일 123개 통과. 산탄·거리·표식/체력 배율·집중 사격·정글·방패·재장전·화산·궁수·로켓·그물·코일·진단 검사를 포함한다. 두 결과는 중복 테스트를 포함하므로 합산하지 않는다.
- 검투사·닌자·사신·궁수·마법사·얼음 마법사·과학자·해커: 8종 × 5맵 × 5난이도 × 2상태 × 3관측 전이, **1,200회에서 전체 반환 런타임 동일**. 입력·메모리·난수 상태·관측/입력 대기열·학습 상태를 포함한다.
- 앱 타입 검사, 변경 TypeScript 파일 lint, 프로덕션 빌드 통과. 빌드는 기존 Browserslist 데이터와 청크 크기 경고를 출력했다.
- 브라우저 실제 플레이·렌더링·전체 프레임 비용과 모든 가능한 전투 상태는 검증하지 않았다.

## 경기 평가와 전술 지표

4개 매치업 × 5맵 × 2진영 × 변경 전후, 패널당 80경기 명세를 마련했다. 개발 시드 `2387916401`, 미사용 시드 `1573068927`을 구현 시점에 고정했고 기존 관리 명세에서 중복이 발견되지 않았다. 구현 직전 동결 AI를 두 버전 모두의 동일 상대에 사용하도록 구성했다. 누적 20분 제한·단일 워커·조건별 체크포인트 및 실행 오류 재개 1회 제한이 있다.

**실행하지 않았으므로 승·무·패/점수율, 평균 실제 산탄 적중 수·교전 거리, 재장전 중 피해, 스킬·궁극기 자원당 효과, 맵별 성능은 모두 미측정이다.** 장면 검사에서 산탄 예상 명중 수가 달라지는 사실을 실제 경기 전술 지표 향상으로 해석하지 않는다.

평가 도구는 실제 기본 공격 투사체 명중 수/공격 사용 수, 시간 가중 교전 거리, 재장전 중 받은 피해, 직접 환경 피해, 스킬·궁극기 피해/사용 마나를 수집하도록 준비했다. `readyFacingAwayMs`는 같은 높이·현재 사거리 내에서 준비 중 반대 방향을 보는 시간의 **대리지표**다. 차단물까지 검사한 정확한 발사 기회 상실량이 아니다. 그물 표식의 간접 기여는 그물 직접 피해/마나에 포함되지 않으며, 환경 발화 피해 전체를 직접 환경 피해로 세지 않는다.

작업 중 구현 파일들이 Git index에 staging된 상태가 관측됐다. 별도의 staging·unstaging 명령이나 커밋은 실행하지 않았으며 해당 index 상태를 보존했다. 최종 도구/보고서 일부에는 별도의 미스테이징 변경이 있으므로, 이후 커밋한다면 전체 작업 트리와 index 차이를 먼저 검토해야 한다.
