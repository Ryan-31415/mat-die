## 5. CPU 재검증 — 미실행

CPU 비교 프로토콜은 준비80회·측정160회·3반복,16회 블록 교차, 사냥꾼/로켓병/궁수×투사체0/20/60/120개로 고정했다. 원시 샘플·시각·순서, 소스 변경 감시, 절전/전원 이벤트 확인, 실행 중만 적용하는 절전 방지와120초 제한을 마련했다. 기존 예산 파일을 초기화하지 않았다.

**워커 시작 전 환경 확인에서 중단됐다.** 현재 AC 연결과 Balanced 계획은 확인했으나 시스템 부하는 두1초 표본에서22.1%,30.4%, 독립된5초 확인에서27.8%였다. 도구의 보수적인 시작 기준25%를 다시 넘었다. 이25%는 이번 도구의 환경 기준이며 사용자 지정 CPU p95 상한+10%와 별개다. 높은 부하의 원인 프로세스를 확정하지 않았다.

벤치마크 워커의 `cpu-attempt.json`과 `cpu-raw.json`은 생성되지 않았다. 최초 PowerShell 파일 직접 호출은 실행 정책에 의해 스크립트 로드 전에 거부됐고, 정책 변경 없이 동일 검증 코드를 인라인 실행해 환경 점검까지 수행했다. 실행된 CPU 측정의 재시도는 없었다. 사전 절전 방지 API 점검은 호출 후 해제했으며 측정용 보호는 부하 점검에서 중단되어 획득하지 않았다.
